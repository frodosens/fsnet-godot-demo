3. 指令状态
普通：低饱和金属图标+奶油文字，不画整行外框。Hover：80ms提亮，轻微上移2px。键盘/手柄focus：常亮琥珀菱形指针+2px轮廓，不能只靠hover。按下：60ms缩至.96。选中：图标108%且显示当前模式，不能和hover混淆。Disabled：灰化55%但仍可读，显示锁/已耗尽标记；悬停/聚焦解释具体原因（已移动、行动已用、法力不足等），不得仅灰色无反馈。Tab/方向键循序，Enter确认，Esc/右键退一级；快捷键必须与实际输入一致。

4. 移动范围与路线 — 精确验收
仅用同一合法性/寻路查询结果，不创建第二套规则。不可通行水面、阻挡、占用格不显示为合法落点。未选落点不显示路线。范围：地面独立覆盖层，青色填充alpha .18-.25、细边alpha .55；攻击范围用锈红边线，不能高饱和盖住地形。
令P[i]=camera.project_position(tile_center(path[i])+vertical_epsilon)，按P逐点折线；相邻逻辑坐标必须Manhattan距离=1，屏幕角度来自相机，禁止固定45度或鼠标直线。底线6px深色、主线3px奶油/琥珀；转角用斜接限长，终点箭头10×8；中间小箭头沿真实段切线，每格最多一枚。路线长度为path.size()-1。例：[ (2,5),(3,5),(3,4),(3,3) ]=3步；仅在这些格均合法时可用此示意。
起点空心环、落点菱形边线与半透明角色轮廓；文本“移动 3/3”必须来自实际路径代价/预算。确认前预览、确认后清除；非法目标立即清除旧路线并解释原因。移动动画必须消费同一路径，不能穿水或穿桥栏，UI与单位轨迹需一致。摄像机改变后每帧重新投影。

5. 目标与战斗预测（本图刻意不显示）
只有攻击/技能模式且悬停合法目标时出现右上目标条：56×56肖像、名字、HP、实际可推导的结算范围，整体≤280×110。移动状态绝不留着虚假目标预览。若规则没有命中率/暴击，则不显示“100%”“暴击”等伪数据。若伤害有0/1随机加成而无法在不消费RNG的情况下确定，展示合法伤害区间，不能泄漏/改变RNG。受伤后生命条跟真实结算事件更新。

6. 伤害艺术字与跳字
保留真实数值和中文字体回退；推荐原生粗像素/方切角数字字体，常规32px、深松绿2px描边+下方2px硬阴影，奶油白填色。负伤数值不强制负号（沿项目语义），治疗带+号、低饱和嫩绿。不得将示例数字烘焙进通用贴图。可用字体资源或0—9、+、−字形图集，但字距和多位数由引擎排版。
常规：打击接触帧t=0生成，0—70ms scale .75→1.2，70—140ms回到1；同时抛物线跳起，140ms到最高点（相对头顶-30px），至420ms落至-8px；420—620ms淡出。整体字组跳跃，多位数逐字延迟≤18ms，不能数字乱序或晚显示数值。水平漂移≤12px，同帧多伤害分泳道错开24px，文字高于特效层且不覆盖HP值。
暴击仅响应真实crit事件：44px、琥珀填色、深色3px描边，起跳42px，峰值1.3倍，保持到700ms；加一笔短冲击划线/小星芒，不加框。若当前规则无暴击，实施样式但不伪造触发。治疗不抖屏、起跳20px。0伤害/免疫/闪避须按真实事件分别显示，不能都当伤害。
Reduced motion：无弹跳/缩放，静止显示并淡出。加速/跳过应立即完成表现，不重复数值、不改变规则/哈希。跳字不能作为结算依据。

7. 验收清单
1280×800与1920×1080实机截图；鼠标/键盘focus和禁用原因；全部角色小头像；合法/非法移动与桥上路径；攻击目标面板仅在正确模式；0/1/两位数/治疗/连续伤害跳字；缺少暴击事件时不伪造；场景缩放无遮挡；规则测试与联网哈希不受UI动画影响。概念图不能替代这些运行时证据。
