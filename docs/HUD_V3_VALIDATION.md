# HUD v3、路径和打击反馈增量（2026-10-26）

这是实际 Godot 原型增量，不是概念图替代运行画面，也不是发布质量认证。

## 已完成

- 小头像、HP/MP、剩余移动次数与行动；上下文菱形指令、焦点/禁用原因、结束回合确认。技能/道具仍来自内容数据。
- 移动范围与路线来自规则中的同一 BFS；移动命令实际消费同一路径。非法悬停清理旧路径。预览不改变 RNG/快照。
- 有界整数暴击概率/倍率，真实事件携带 is_critical。伤害预测枚举合法随机分支，处理多效果中途死亡和治疗，不消耗 RNG。无命中/格挡机制，未伪造这些结果。
- 六角色真实 iso4 静止/行走图（24 idle + 96 walk）；六角色侧视攻击与受击资源。关键帧数量有限，held tick 不冒称独立绘制帧。
- 武器 socket/目标躯干接触、箭尖接触；局部白闪、短 hitstop、轻位移、冲击、跳跃伤害数字。减弱动画、跳过、连续事件清理不改变规则 hash。
- 原创合成 WAV、音量/静音；临时功能音效，非音频艺术终稿。伤害数字为已有合法字体的描边排版，不是新绘制数字字体。
- 连续河岸、桥侧几何、较大斜屋顶旅店、独立树/草/芦苇/物资/灯柱；卡片装饰不改变通行规则。参考图在 docs/art-reference，未作为战场背景。

## 实测

Linux x86_64；Godot 4.6.3；Lua 5.4.7；OpenGL Compatibility / Mesa 25.0.7 llvmpipe LLVM 19.1.7。

- tools/test.sh：439 项计数断言通过；场景输入、20 次最大内容预算测试及三组真实 fsnet 三进程联网/重连测试通过。
- 扩展联网 step 7 双客户端 hash：f42bf7e6c26f6691054c35ffe964c273e8910d56f5b36ec776bd8cd9e6f8b4a8。
- 16 AI / 16×16 内容微基准：20 次 p50 8887µs、p95 11183µs、max 13758µs，快照 1013B。共享 AMD EPYC 9V74 主机、5 CPU affinity；不是网络端到端性能指标。
- 图形测试验证 flash=0 的 280 个像素与原图一致，flash=1 仅角色变白。修复了 shader 重复乘纹理导致角色变暗。
- capture_impact_path.gd 实际运行：预览与已执行移动路径相同；100% 暴击是显式测试内容 fixture，非默认概率。
- 截图 context-actions/shared-path/target-preview/critical-contact 为运行时画面。1280×800 与 1728×1080（1920×1080 窗口的保持纵横比渲染区域）；未冒称后者为完整 1920×1080 布局验收。
- 录制脚本 tests/record_all_combat.gd、record_all_walk.gd 使用合法 fixture 和真实命令；固定 30 FPS 离线 MovieMaker 不是实时吞吐基准。

## 仍有边界

地图树木重复、直线河岸、地表过渡和部分遮挡仍需美术迭代；当前并未达到参考稿整体精细度。行走存在个别支撑相位/脚尖问题，近景动画仍稀疏；尚无完整死亡/转身/呼吸动作。960×600 和完整 16:9 重排尚未完成验收。上下文指令位置已避让路径，但所有角色密集遮挡组合未穷尽。

联机仍仅本机 loopback 共控队伍，无公网/账号/持久服务端验收；Windows/macOS 导出未验证。规则源码 hash 已变化，旧版本存档按现有兼容性检查拒绝，不做隐式迁移。
