# Generated bottom dock integration

The approved runtime art package (d759eee + cf00b77) replaces the actor arc. All button chrome, panels, bars and icons come from assets/ui/bottom_dock_reference; provenance distinguishes generated reference-conditioned artwork from the separately approved Mara illustration. No concept images or review/demo media are added to Git.

The UI uses a 1586×992 canvas, uniform fit and centering. Five button origins/sizes exactly follow layout.json (124×127, 132 pitch), as do status panel, portrait, bars, phase panel, end-turn, confirm and cancel positions. Dynamic names, values and commands are native controls. Font sizes are enlarged when required for small-window readability; the concept's generated font is not an available font file, so pixel-perfect typography is not claimed. Other characters use their existing approved portraits. Unknown Mod portraits safely show no image rather than generating a load error.

Move replaces the dock with destination distance/cost and actual Confirm/Cancel buttons. Selecting a destination does not mutate rules. Confirm submits the previously validated path proposal; Cancel, reselect, pause/save and authoritative state changes invalidate it. Wait is a separate per-unit Lua command, not End Turn. The earlier functional groundwork documents snapshot/version handling.

Range uses separate generated fill/border textures on horizontal world-cell quads with one UV projection; the fill alpha is authored near 32/255 and is not multiplied again. Legacy tile overlay fill is disabled. Generated gold destination frame uses the same cell quad. The generated arrowhead follows the actual projected BFS-derived route tangent; the continuous route remains inside authorized cells. The destination ghost uses the selected character texture with warm translucent modulation. Ground textures remain depth-tested below characters. The renderer's actual camera projection is retained for fixed-background picking alignment; no extra 0.7071 warp is imposed on an already projected world quad.

Validation: Godot4.6.3, Linux OpenGL Compatibility/Mesa llvmpipe. Full regression: 1588 checks plus five three-process fsnet consistency/reconnect scenarios, including wait. Old arc-only geometry tests are retained as historical files but replaced in the active suite with bottom-dock tests. Full UI new-game/story/skill/item/AI/victory/defeat/save/load flow passes. Actual button event tests cover Move/Confirm/Cancel/Wait at 1280×800 and960×600. Synthetic event tests do not constitute physical touchscreen/controller validation.

Review captures and 9-second actual mouse interaction recording are kept outside the repository for native-chat delivery. User deletion of docs/runtime-video is preserved. This is a measured layout implementation using approved generated materials, not a claim that all scene pixels equal flattened concept images.
