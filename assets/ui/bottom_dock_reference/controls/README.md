# Reference-generated small controls

Ten native-scale RGBA controls extend the approved dark-bluegray / restrained bronze / ivory UI. All runtime shapes were generated by built-in ImageGen from the approved button, panel, and icon references, then cropped and normalized. No screenshots were used as runtime extraction sources, and no runtime art was redrawn by script.

## Runtime contract

| PNG in this directory | Native logical size | Stretch policy |
| --- | --- | --- |
| `checkbox_unchecked.png` | 24×24 | Preserve aspect ratio; checked counterpart identical ink bounds |
| `checkbox_checked.png` | 24×24 | Preserve aspect ratio; checked glyph + selected copper fill |
| `slider_track.png` | 96×8 | Horizontal nine-slice, margins L/T/R/B = 4/2/4/2 |
| `slider_thumb.png` | 20×24 | Do not stretch; independent from track |
| `scrollbar_track.png` | 8×96 | Vertical nine-slice, margins 2/4/2/4 |
| `scrollbar_thumb.png` | 10×32 | Vertical nine-slice, margins 2/4/2/4; center over 8px track |
| `indicator_up.png` | 16×16 | Preserve aspect ratio |
| `indicator_down.png` | 16×16 | Preserve aspect ratio |
| `indicator_left.png` | 16×16 | Preserve aspect ratio |
| `indicator_right.png` | 16×16 | Preserve aspect ratio |

Native dimensions are logical rendering dimensions at UI scale 1, not high-resolution source sizes. Do not load these as 128px icon masters. Tracks and thumbs are deliberately independent so the engine can clip/stretch them and move thumbs normally. Use at least 44px interaction targets in engine layout where desired; those bounds are **not** baked into the bitmap.

Checkboxes were visually checked at 16, 20, and 24px. Direction indicators share one generated up-triangle, normalized once and rotated losslessly for exactly consistent geometry. The other originally generated triangle cells remain in the retained source for provenance. Channels and scroll thumb preserve their generated endcaps and extend only the uniform generated center; no shape was synthesized.

## States and limitations

Selected checkbox is distinguished by its checkmark as well as copper fill. To disable controls, prefer retaining full alpha and using restrained engine RGB modulation (approximately 0.82) rather than low-alpha fading; retain the checked glyph and actual disabled/input-blocked semantics. This is a rendering recommendation, not a formal accessibility-conformance claim. Final in-game context, theme assignment, keyboard focus, disabled labeling and interaction target sizes are the integration owner's responsibility.

Palette is intended for dark UI. The light-background contact sheet is an alpha/edge check, not a promised light-theme palette. Engine integration was not performed by this asset-only task.

## Verification and provenance

`manifest.json` records exact source regions, dimensions, slice margins, hashes, and alpha checks. `metadata/provenance.json` contains exact source/prompt/reference hashes. `generation-prompt.txt` is the complete production prompt. `metadata/qa-report.json` contains native-scale component and scale checks. All runtime images have fully transparent outer borders and one intentional connected component.

Only runtime PNGs and textual metadata are intended for the Git asset package. Keep `originals/` and `review/` local. Review images (`controls-native-and-alpha.png`, `checkbox-16-20-24.png`) are native-chat previews only, not runtime screenshots to upload. No code or Git state was changed by this asset-generation task.
